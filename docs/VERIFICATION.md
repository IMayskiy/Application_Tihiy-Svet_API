# Проверка публикации для портфолио

Дата: **16 ноября 2026 года**. Среда текущего автоматического прогона: Windows, Node.js **26.13.1**.

## Автоматические тесты

Команда: `npm test` (эквивалент `node --test tests/*.test.mjs`). Результат: **20 успешно, 0 ошибок**. Все ответы OpenAI в тестах задаются отдельным тестовым транспортом. Настоящие вызовы API не выполняются.

| Область | Количество | Что подтверждено |
| --- | --- | --- |
| Карточка | 7 | Строгая схема, `null`, вопросы, отказ, незавершённый ответ, отклонение лишних полей и некорректных чисел |
| Каталог | 4 | Поиск, расчёты, неизвестный срок, отсутствие бюджета, цикл функции, запрет подмены товара и функции |
| Сохранение | 8 | Подтверждение, актуальность, повторы и конкурирующие запросы, повторное открытие хранилища, сбои до и после записи |
| Ошибки | 1 | Разные безопасные сообщения для доступа, средств, частоты и тайм-аута |

Тестовые записи создаются в отдельных временных папках `tests/crm-temp-*`, а затем удаляются. Пользовательская CRM не участвует. Тест каталога использует локальный HTTP-сервер.

## Что этот результат не подтверждает

- Действительность пользовательского ключа, баланс и доступ к выбранной модели.
- Качество извлечения данных и устойчивость настоящей модели ко всем инструкциям в сообщении покупателя.
- Полный сценарий с реальным API и реальным подтверждением сохранения.
- Работу с несколькими пользователями, публичную эксплуатацию и внешнюю CRM.
- Измеренную экономию времени, продажи или окупаемость.
- Восстановление после аварийного завершения процесса прямо во время записи файла.

В рамках упаковки интерфейс приложения не изменялся. Историческая визуальная проверка описана в [ACCEPTANCE.md](../ACCEPTANCE.md) и относится к 10 ноября; она не является новой проверкой всех заполненных состояний экрана.

## Проверка перед живой демонстрацией

Пользователь выполняет [сценарий демонстрации](DEMO.md): сверяет результат с контрольными примерами, проверяет отмену и явное подтверждение, отображение устаревших данных, чтение сохранённой записи, окно просмотра и управление клавиатурой на нужном размере экрана. Эти действия могут обращаться к API и создавать локальные записи.

## Состав публикации

Для GitHub отобраны исходники, интерфейс, каталог, контрольные примеры, тесты, lock-файл зависимостей, документы и проектные скиллы. Шаблон `.env.example` создан заново с пустыми значениями.

Содержимое настоящего `.env` не читалось. Из отправки исключены `.env`, `data/generated/`, `node_modules/`, `.tools/`, `backups/`, логи и временные тестовые хранилища. Проверка состава не означает гарантии отсутствия любых возможных чувствительных данных; публикация выполняется по явному списку файлов.

Перед загрузкой проверены 37 отобранных файлов: внутренних битых Markdown-ссылок и совпадений с проверяемыми шаблонами ключей OpenAI, токенов GitHub, Bearer-токенов и закрытых ключей не обнаружено. Сервис проверки секретов GitHub недоступен для этого репозитория: GitHub Advanced Security не включён. Локальная проверка по шаблонам не заменяет полный аудит.

Синтаксис `server.mjs` и `public/app.js` проверен через `node --check`. У двух скиллов проверены заголовок, имена, описания и отсутствие незавершённых шаблонов. Штатный Python-валидатор не удалось запустить: доступный `python.exe` оказался неработающим системным ярлыком. Базовые проверки выполнены отдельно на JavaScript; поведенческий прогон скиллов не выполнялся.
