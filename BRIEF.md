# Лид студия Тихий свет

Внутреннее приложение магазина светильников «Тихий свет» для работы с обращениями покупателей. Приложение помогает менеджеру обработать сообщение покупателя, получить структурированную карточку, сверить сведения с каталогом и сохранить черновик обращения после подтверждения. Это не заказ, резерв или публичный сервис.

## Этапы
1. Обычный текстовый ответ через реальный Responses API.
2. Карточка через Structured Outputs.
3. Полный цикл get_catalog_item через function calling и наш локальный HTTP API каталога.
4. Сохранение через create_lead после серверной проверки подтверждения и с защитой от повторов.

Не реализовывай будущие этапы раньше явного запроса. В интерфейсе сохраняй результаты уже сделанных этапов. Текущий объём работ — локальное приложение и каталог из файлов проекта. Публикация, внешняя CRM и обработка изображений в него не входят.

## Данные и смысл
Главное сообщение: examples/01_main.txt. Все контрольные значения: examples/expected.json. Каталог: catalog.json. Источник запроса клиента, источник каталога и результаты расчёта отображаются раздельно. Сумма заказа является расчётной стоимостью нужного количества, а не подтверждением возможности поставки.

Все поля строгой схемы присутствуют. Неизвестные значения nullable. Бизнес-проверка требует положительного целого количества и неотрицательного бюджета, если бюджет известен. Для вопросов отмечай отсутствующие товар, количество, бюджет, контакт и точный адрес. Желаемый срок сохраняй текстом. Если клиент явно оставил срок на согласование, отсутствие конкретной даты само по себе не делает черновик ошибочным.

Состояние ready_for_review означает готовность черновика к проверке менеджером, а не подтверждение исполнения заказа. Needs_clarification означает недостающие сведения или расхождения. Черновик с вопросами можно сохранить после явного подтверждения менеджера и проверки актуальности карточки. Поломанные или устаревшие данные сохранять нельзя. При смене входного текста сбрасывай возможность использовать старую карточку для следующих действий.

## Результат проверки главного сообщения
12 × 5900 = 70800 ₽, бюджет 60000 ₽, превышение 10800 ₽, остаток 8, нехватка 4. Дата поставки неизвестна. Пожелание «20 ноября» не становится подтверждённой датой. Исходные 12 штук не меняются на 8.

## Техническая граница
Сервер доступен только на loopback 127.0.0.1. Статические файлы только из public. Секреты только в серверном процессе. Модель приложения из OPENAI_MODEL, плановый ID gpt-6-luna; модель чата Codex может быть другой. Один локальный пользователь, без публичного размещения и без обещаний промышленной готовности. Сохранение локальных данных атомарное с устойчивой идемпотентностью для одной операции.

Тесты с подменным транспортом изолированы от пользовательского интерфейса. Не имитируй успешные вызовы OpenAI в приложении. Запросы к OpenAI запускает пользователь кнопками в приложении. Наличие ключа или успешный автотест не доказывает доступность API-аккаунта.
