# Проектные скиллы

Эти два скилла созданы при подготовке репозитория к портфолио. Они описывают работу агента с текущим проектом и не заявляются как инструменты, использованные при первоначальной разработке.

| Скилл | Когда применять |
| --- | --- |
| [tihiy-svet-maintenance](tihiy-svet-maintenance/SKILL.md) | Изменение и локальная проверка приложения с сохранением бизнес-ограничений |
| [tihiy-svet-demo](tihiy-svet-demo/SKILL.md) | Подготовка демонстрации и обновление описания кейса по фактическому состоянию |

Это инструкции для агента, не функции приложения. Они не отправляют данные и не вызывают API сами по себе. Названия и содержимое универсальных сторонних скиллов из личного окружения в репозиторий не копировались.

## Использование

Без установки: откройте проект в агенте и попросите «Прочитай `skills/tihiy-svet-maintenance/SKILL.md` и выполни …» либо укажите второй скилл.

Для установки в Codex скопируйте нужную папку с `SKILL.md` в каталог `skills` вашего `CODEX_HOME` и откройте новую сессию. В этом окружении такой каталог — `D:\.codex\skills`; на другой машине путь может отличаться. Не перезаписывайте установленный одноимённый скилл без проверки. После обнаружения можно вызывать `$tihiy-svet-maintenance` или `$tihiy-svet-demo`.

Скиллы предполагают открытый корень проекта с `BRIEF.md`, `AGENTS.md` и исходниками. Синтаксическая проверка скилла не доказывает качество его поведения во всех задачах; автоматическая установка и отдельный поведенческий прогон в этой поставке не выполнялись.
